# Prompt-to-Prompt Image Editing with Cross Attention Control

## PROFIL

The paper argues that text-driven image editing in diffusion models can be achieved solely through prompt manipulation by injecting cross-attention maps from a source generation into the edited-prompt generation process, preserving original composition without spatial masks or model retraining. It positions itself against state-of-the-art inpainting methods that require user-provided masks, which discard structural information within masked regions and preclude edits such as texture modification. The central observation, developed through analysis of Imagen's cross-attention layers, is that pixel-to-text interactions encoded in attention tensors govern spatial layout, so controlling these maps enables token replacement, phrase addition, and semantic weight tuning. For arts education, the method's demonstration that internal model representations can be steered through textual intervention offers a concrete case for teaching how generative systems negotiate semantic and spatial structure.

## WISSEN

### Problem Framing and Thesis

Large-scale text-driven synthesis models generate diverse images from prompts, but editing is innately challenging: even minor prompt modifications yield entirely different outputs. State-of-the-art methods mitigate this by requiring users to provide spatial masks for **inpainting**, localizing edits while discarding structural information within masked regions—preventing capabilities like texture modification. Against this, the thesis pursues an intuitive **Prompt-to-Prompt** editing framework controlled by text alone, without masks, model training, fine-tuning, extra data, or optimization. The key observation is that **cross-attention maps**—high-dimensional tensors binding pixels to text tokens—contain rich semantic relations critically affecting the generated image. By injecting these maps during the diffusion process, one controls which pixels attend to which tokens at which steps. Three manipulation modes follow: (1) replacing a token while fixing attention maps to preserve composition; (2) adding tokens while freezing attention on previous ones for global edits; (3) amplifying or attenuating a word's semantic effect. A trade-off between fidelity to the edited prompt and fidelity to the source image is identified.

### Demarcation from Previous Work

GAN-based text-driven image editing, paired with CLIP, succeeds on curated datasets but struggles with diverse data. Diffusion models surpass GANs in generation quality over diverse datasets; existing approaches either perform global edits or require user-provided masks for local manipulation. Bar-Tal et al. achieve mask-free localized editing but are limited to texture changes (not structural transformations like bicycle→car) and require per-input network training. Large-scale text-to-image models (Imagen, DALL-E2, Parti) lack fine-grained control: changing a single prompt word often alters the entire image structure. The proposed method requires textual input only, extracting spatial information from the generative model's internal cross-attention layers. By injecting source-image attention maps into the target generation process, it preserves spatial layout during word swaps and injects only unchanged-token maps when adding phrases, enabling both local and global editing without masks.

### Methodological Problem and Key Observation

Given an image *I* generated by a text-guided diffusion model from prompt *P* and seed *s*, the goal is producing an edited image *I*∗ guided solely by an edited prompt *P*∗ — e.g., changing color, material, or replacing a bicycle with a scooter — while preserving original appearance and structure. Unlike prior work, no user-defined mask is used. A naive attempt — fixing the internal randomness and regenerating with the edited prompt — fails, yielding a completely different image with different structure and composition. The **key observation** is that structure and appearance depend not only on the random seed but on the **pixel-to-text interaction** mediated through **cross-attention layers**. By modifying this interaction — specifically, injecting the **cross-attention maps** of the input image *I* — the original composition and structure are preserved, enabling **Prompt-to-Prompt** image editing.

### Cross-Attention in Text-Conditioned Diffusion Models

Using Imagen as backbone, composition is determined at 64×64 resolution; only the text-to-image model is adapted. During noise prediction, deep spatial features φ(z_t) project to query Q, text embedding ψ(P) projects to key K and value V via learned linear projections. Attention maps M = softmax(QK^T/√d) define token j's weight on pixel i. Output MV updates spatial features. Multi-head attention runs in parallel for expressiveness. Imagen uses two attention types: cross-attention layers and hybrid attention, which concatenates text embeddings to self-attention key-value pairs. The method intervenes only in the cross-attention part of hybrid attention—modifying solely the last channels referring to text tokens.

### Cross-attention Control Framework

The spatial layout and geometry of a generated image depend on cross-attention maps; structure is determined in early diffusion steps. Therefore, attention maps from generation with original prompt P can be injected into a second generation with modified prompt P*, preserving structure while allowing content edits. A general algorithm runs both prompts simultaneously with fixed random seed, applying an attention-based manipulation at each step via an Edit function. Three operations instantiate this: **Word Swap** injects source attention maps up to a timestamp τ, limiting over-constraining of geometry while guiding composition. **Adding a New Phrase** injects only over common tokens using an alignment function A mapping target token indices to source indices (or None). **Attention Re-weighting** scales a single token's attention map by parameter c ∈ [-2, 2], strengthening or weakening its effect while leaving other maps unchanged.

### Text-Only and Real Image Editing Applications

The method enables text-only editing by controlling spatial layout via cross-attention injection. Localized editing replaces words (e.g., 'lemon' to 'pumpkin') preserving geometry and background, unlike naive prompt feeding. Injecting attention for specific words or diffusion steps controls fidelity; more steps increase fidelity, though not always optimal. Adding specifications (e.g., 'crushed') retains original attention maps while generating new details. Global editing affects all parts while retaining composition (e.g., adding 'snow', sketch-to-photo). For effects difficult to textually quantify (e.g., snow amount), fader control re-scales the attention of a specified word to adjust its magnitude. Real image editing requires inversion. Naive Gaussian noise causes distortion; DDIM inversion (reversing diffusion x0→xT) improves results but faces a distortion-editability tradeoff where reducing classifier-free guidance improves reconstruction but limits manipulation. To alleviate this, unedited regions are restored using a mask extracted directly from attention maps, requiring no user guidance, functioning even with naive DDPM inversion.

### Conclusions and Outlook

Cross-attention layers in text-to-image diffusion models carry interpretable spatial maps that bind prompt words to the synthesized image's spatial layout. Manipulating the prompt thus directly controls attributes, enabling local and global editing and allowing users to navigate a semantic textual space with incremental changes rather than regenerating from scratch.

Limitations requiring follow-up work:
- Inversion produces visible distortion on some test images.
- Inversion requires a user-supplied suitable prompt, challenging for complicated compositions; inversion for text-guided diffusion models is an orthogonal endeavor to this work.
- Attention maps are low-resolution because cross-attention sits at the network's bottleneck, bounding precise localized editing; incorporating cross-attention in higher-resolution layers is suggested but requires analyzing the training procedure.
- The method cannot spatially move existing objects across the image.

## GLOSSAR

- **cross-attention maps** — High-dimensional tensors internal to text-conditioned diffusion models that bind spatial pixel locations to textual tokens and encode semantic relations governing the generated image.
- **Prompt-to-Prompt** — An image editing framework that manipulates only the textual prompt while injecting or freezing cross-attention maps from the original generation to control edits without spatial masking.
- **inpainting** — A masking-based editing approach where the user specifies a spatial region to be regenerated while the surrounding background is preserved, discarding structural information within the masked area.
- **attention injection** — Injecting attention weights from a source image's diffusion process into the target generation to preserve spatial structure across prompt edits.
- **cross-attention layers** — High-dimensional layers in diffusion models whose spatial maps link prompt words to the spatial layout of the synthesized image.
- **spatial attention maps** — Per-textual-token maps that encode where each token influences the generated image, used to control spatial layout and geometry.
- **pixel-to-text interaction** — The coupling between image pixels and text embeddings during the diffusion process that determines generated structure and appearance.
- **cross-attention** — Mechanism fusing visual and textual feature embeddings via query-key-value projections, producing spatial attention maps per textual token.
- **hybrid attention** — Layers acting as both self-attention and cross-attention by concatenating text embeddings to the key-value pairs of self-attention.
- **attention maps M** — Matrices whose cells M_ij define the weight of the j-th token's value on pixel i, computed from query-key similarity.
