# Prompt-to-Prompt Image Editing with Cross Attention Control

## PROFIL

Written by Amir Hertz, Ron Mokady, Jay Tenenbaum, Kfir Aberman, Yael Pritch, and Daniel Cohen-Or (Google Research and Tel Aviv University), the paper introduces "Prompt-to-Prompt," a method for editing images generated by text-conditioned diffusion models using text prompts alone, without user-provided spatial masks, model training, fine-tuning, extra data, or optimization. Its central claim is that the cross-attention layers inside diffusion models such as Imagen bind pixels to text tokens and control the spatial layout and geometry of the generated image, so injecting or manipulating these attention maps during generation enables editing by changing only the prompt. The paper first situates the method against GAN-based text-driven manipulation (often with CLIP), diffusion-based editing requiring masks (Kim et al., Avrahami et al., GLIDE), and Bar-Tal et al.'s mask-free but texture-limited approach. It then details the cross-attention mechanism, a general algorithm running the diffusion process for source and target prompts simultaneously, and three editing operations: Word Swap, Adding a New Phrase, and Attention Re-weighting. Applications cover text-only localized and global editing, fader control over a word's effect, and real-image editing via deterministic DDIM inversion, with attention-derived masks restoring unedited regions. The conclusion states that cross-attention layers hold interpretable spatial maps enabling local and global editing, while noting limitations: inversion distortion, low-resolution attention maps bounding editing precision, and inability to spatially move objects. An appendix covers DDPM/DDIM background, cross-attention in Imagen's three models, and additional word-swap, specification, and re-weighting results. For arts education, the paper is usable in disciplines and situations involving generative image-making and digital media—e.g., prompt-based image editing, stylization, and iterative refinement of generated artworks—where students explore how textual prompts and model internals shape visual composition.

## WISSEN

### Purpose and Thesis (pp. 1–2)

This paper by Amir Hertz, Ron Mokady, Jay Tenenbaum, Kfir Aberman, Yael Pritch, and Daniel Cohen-Or (Google Research and Tel Aviv University) introduces "Prompt-to-Prompt," a method for editing images generated by text-conditioned diffusion models using text prompts alone, without any user-provided spatial masks. The central problem is that in large-scale language-image (LLI) models such as Imagen, DALL·E 2, and Parti, even a small change to the text prompt typically produces a completely different image, which conflicts with the essence of editing: preserving most of the original image. Existing solutions require users to draw masks, which is cumbersome and discards structural information inside the masked region. The authors' key observation is that the cross-attention layers inside the diffusion model bind pixels to text tokens, and that these attention maps control the spatial layout and geometry of the generated image. By injecting or manipulating these attention maps during generation, one can edit an image by changing only the text prompt. The method requires no model training, fine-tuning, extra data, or optimization. (pp. 1–2)

### Related Work (pp. 2–3)

The authors situate their work in the literature on image editing:

- Text-driven manipulation with GANs, often combined with CLIP's joint image-text representation, produced realistic text-only editing; Bau et al. added user masks to localize such edits. However, GAN-based editing works well mainly on highly curated datasets (e.g., human faces) and struggles on diverse data.
- Diffusion-based works include Kim et al. (global changes) and Avrahami et al. (local manipulations with user-provided masks). Crowson et al. used VQ-GAN as a backbone for more expressive generation.
- Bar-Tal et al. proposed mask-free text-based localized editing, but it mainly changes textures rather than complex structures (e.g., cannot turn a bicycle into a car) and requires training a network per input.
- Large text-to-image models (Imagen, DALL-E 2, Parti) lack control over a generated image via text alone; works like GLIDE and others assume the user provides a mask.

Unlike all of these, the present method needs only textual input, extracting spatial information from the model's internal layers. (pp. 2–3)

### Method (pp. 4–8)

**Setting.** An image I was generated by a text-guided diffusion model (Imagen is the backbone) from prompt P and random seed s; the goal is to edit it using only a modified prompt P*. Simply fixing the random seed and regenerating with the new prompt fails—it yields a completely different structure. The authors' key idea: the image's structure depends not only on the seed but on the pixel-to-text interaction in the cross-attention layers. Injecting the cross-attention maps of the original generation preserves the original composition. (pp. 4–5)

**Cross-attention in text-conditioned diffusion models.** Each diffusion step predicts noise from a noisy image z_t and text embedding ψ(P) using a U-shaped network. Deep spatial features φ(z_t) are projected to a query matrix Q = ℓ_Q(φ(z_t)); the text embedding is projected to keys K = ℓ_K(ψ(P)) and values V = ℓ_V(ψ(P)). The attention maps M = softmax(QK^T / √d) have cells M_ij giving the weight of token j's value on pixel i; the cross-attention output is M·V, which updates the spatial features. Multi-head attention is used in practice. Imagen conditions on text through cross-attention layers and "hybrid" attention layers (self-attention with the text embedding concatenated to the key-value pairs); the paper refers to both as cross-attention, since the method intervenes only in the cross-attention part. Since composition and geometry are mostly determined at 64×64 resolution, only the text-to-image diffusion model is adapted; the super-resolution stages are used as-is. Visualization of attention maps shows pixels attend to the words describing them (e.g., bear pixels attend to "bear"), and that image structure is determined in the early diffusion steps. (pp. 4–5)

**General algorithm.** Let DM(z_t, P, t, s) be one diffusion step outputting the noisy image z_{t-1} and attention map M_t; DM(z_t, P, t, s){M ← M̂} denotes overriding the attention map with M̂ while keeping the values V from the supplied prompt. M*_t is the map produced with the edited prompt. Edit(M_t, M*_t, t) is a general edit function. Algorithm 1 runs the diffusion process for both prompts simultaneously with fixed internal randomness:

1. Input: source prompt P, target prompt P*, random seed s.
2. Output: source image x_src and edited image x_dst.
3. Sample z_T ~ N(0, I) with seed s; set z*_T ← z_T.
4. For t = T, T-1, ..., 1:
   - z_{t-1}, M_t ← DM(z_t, P, t, s)
   - M*_t ← DM(z*_t, P*, t, s)
   - M̂_t ← Edit(M_t, M*_t, t)
   - z*_{t-1} ← DM(z*_t, P*, t, s){M ← M̂_t}
5. Return (z_0, z*_0).

The forward call for M*_t can be skipped by applying the edit inside the diffusion forward function, and both images can be processed in the same batch, so there is only one step of overhead relative to normal inference. (pp. 5–6)

**Editing operations** (the three instantiations of Edit):

1. **Word Swap** — replacing tokens, e.g., P = "a big red bicycle" to P* = "a big red car". The source attention maps are injected into the edited generation, but full injection may over-constrain geometry for large structural changes. A softer constraint limits injection to steps before a timestamp parameter τ; since composition is determined early, this guides composition while allowing geometric freedom for the new prompt. Different tokens may receive different numbers of injection timestamps, and if the two words have different token counts, maps can be duplicated/averaged via an alignment function. (pp. 6–7)
2. **Adding a New Phrase** — e.g., P = "a castle next to a river" to P* = "children drawing of a castle next to a river". An alignment function A maps a token index in P* to the corresponding index in P (or None if no match); attention injection is applied only over the common tokens, with a timestamp τ optionally limiting the number of injection steps. This enables stylization, specification of object attributes, and global manipulations. (pp. 7–8)
3. **Attention Re-weighting** — strengthening or weakening a token's effect, e.g., making a "fluffy red ball" more or less fluffy. The attention map of the chosen token j* is scaled by a parameter c ∈ [-2, 2]; all other maps remain unchanged. (p. 8)

### Applications (pp. 8–10)

- **Text-only localized editing:** Replacing "lemon" with "pumpkin" in "lemon cake" preserves the layout, geometry, and background (top-left lemons become pumpkins), whereas naive regeneration with "pumpkin cake" gives a completely different geometry even with the same seed under deterministic DDIM. The method handles hard cases like "pasta cake" (a cake of pasta layers with tomato sauce). Injecting only the attention of a single word—"butterfly" in "A photo of a butterfly on..."—preserves that object while replacing its context; the butterfly plausibly sits on all substitute objects. The method performs structural modifications, not just texture changes, e.g., "bicycle" to "car". Injecting attention over more diffusion steps increases fidelity to the original image, but the optimum is not necessarily full injection, so the number of injection steps gives the user control over fidelity. Adding specifications such as "crushed" to a car adds details while preserving the background. (pp. 8–9)
- **Global editing:** Composition preservation also matters when the whole image changes—adding "snow" or changing lighting retains object locations and identities; examples include translating a sketch into a photo-realistic image and inducing an artistic style. (p. 9)
- **Fader control via attention re-weighting:** For prompts like "snowy mountain," where the desired amount of snow is hard to express in words, the user controls the magnitude of a word's effect by re-scaling its attention, e.g., "My fluffy( ) bunny doll" with varying fluffiness. (pp. 9–10)
- **Real image editing:** Editing a real image requires inversion—finding an initial noise vector that reproduces the image. A naïve approach (adding Gaussian noise, then denoising) causes significant distortion; the authors adopt an improved inversion based on deterministic DDIM, running the diffusion process in reverse (x_0 → x_T). This often works, but not always, partly due to a distortion-editability tradeoff: reducing the classifier-free guidance parameter improves reconstruction but limits manipulation strength. To alleviate failures, they restore unedited regions using a mask extracted directly from the attention maps—no user guidance needed—which works even with the naïve DDPM inversion scheme; a cat's identity is preserved under various edits. (p. 10)

### Conclusions and Limitations (p. 11)

The paper shows that cross-attention layers in text-to-image diffusion models hold interpretable spatial maps tying prompt words to image layout, enabling local and global editing through prompt manipulation alone, and letting users navigate a semantic textual space with incremental changes rather than regenerating from scratch. Limitations: (1) the current inversion process visibly distorts some real images and requires the user to supply a suitable prompt, which is hard for complicated compositions—inversion is an orthogonal problem left to future work; (2) attention maps are low-resolution because cross-attention sits at the network's bottleneck, bounding the precision of localized editing—incorporating cross-attention in higher-resolution layers is suggested for future work; (3) the method cannot spatially move existing objects within the image. (p. 11)

### Appendix: Background and Additional Results (pp. 15–19)

- **Diffusion models (A.1):** DDPMs model a forward Markov chain from data x_0 to noise, with Gaussian transitions q(x_t | x_{t-1}) := N(x_t; √(1-β_t) x_{t-1}, β_t I) under a schedule β_0,...,β_T ∈ (0,1); for large T, x_T is nearly isotropic Gaussian. x_t can be expressed directly as a linear combination of noise and x_0, with α_t := ∏(1-β_i). The reverse process is approximated by a parameterized Gaussian network predicting the noise ε_θ(x_t, t), trained by maximizing a variational lower bound. In DDIM, sampling is made deterministic by setting σ_t = 0 at all steps. (pp. 15–16)
- **Cross-attention in Imagen (A.2):** Imagen comprises three text-conditioned diffusion models: a text-to-image 64×64 model (cross-attention at resolutions [16, 8], hybrid attention at [32, 16, 8]); a 64×64 → 256×256 super-resolution model (hybrid attention in the bottleneck at resolution 32); and a 256×256 → 1024×1024 super-resolution model (cross-attention only in the bottleneck at resolution 64). (p. 16)
- **Additional results (B):** Word-swap examples include "cat riding on a bicycle" (cat→dog, chicken), "house with a flag on a mountain" (house→hotel, tent), "A basket full of apples" (basket→bowl, box; apples→oranges, chocolates, cookies), and "A ball between two chairs on the beach" (ball→frisbee, bucket). Adding-specification examples include a bear wearing sunglasses ("squared," "geeky," "rounded" sunglasses; beer or coffee drink), a butterfly on a flower ("spikey," "wither," "origami," "wooden," "candy-made" flowers), and a mushroom in the forest ("wet," "dry," "line art," "plastic," "neon" variants). Attention re-weighting examples include "Photo of a field of poppies at night" with varying effect strength. (pp. 16–19)

## GLOSSAR

- **Prompt-to-Prompt** — The paper's editing framework in which images are edited by modifying only the textual prompt, with manipulations infiltrated through the diffusion model's cross-attention mechanism and no specifications in image pixel space.
- **Cross-attention maps** — High-dimensional tensors M (computed as softmax(QK^T/√d)) that bind image pixels to text tokens; cell M_ij defines the weight of token j's value on pixel i.
- **Attention injection** — Overriding the attention maps of an edited-prompt generation with those from the original generation, while keeping the values V from the edited prompt, to preserve the original composition.
- **Word Swap** — An editing operation replacing tokens in the prompt (e.g., "bicycle" to "car") while injecting source attention maps, optionally limited to steps before a timestamp τ to avoid over-constraining geometry.
- **Adding a New Phrase** — An editing operation that injects attention only over tokens common to both prompts, using an alignment function A, while allowing new attention to flow to newly added tokens.
- **Attention Re-weighting** — An editing operation scaling the attention map of a chosen token by a parameter c ∈ [-2, 2] to strengthen or weaken that word's semantic effect on the image.
- **Fader control** — Continuous user control over the magnitude of a specific word's effect (e.g., amount of snow, degree of fluffiness) achieved through attention re-weighting.
- **Hybrid attention** — An Imagen layer acting as both self-attention and cross-attention by concatenating the text embedding sequence to the key-value pairs of each self-attention layer.
- **Inversion** — The process of finding an initial noise vector that produces a given real image when fed into the diffusion process, here based on deterministic DDIM run in reverse (x_0 → x_T).
- **Distortion-editability tradeoff** — The observed tension whereby reducing the classifier-free guidance parameter improves reconstruction of real images but constrains the ability to perform significant manipulations.
- **Timestamp parameter (τ)** — The parameter determining until which diffusion step attention injection is applied, exploiting the fact that composition is determined in early steps.
- **Alignment function** — A function mapping a token index in the target prompt to the corresponding token index in the source prompt (or None if unmatched), used when adding a new phrase or when swapped words have different token counts.
